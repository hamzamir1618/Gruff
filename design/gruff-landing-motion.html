    Motion tokens

    Four curves, four speeds

    Every animation uses one of these curves and one of these durations. That keeps twenty different effects feeling like one brand, and gives developers a short list to build from.

    Presscubic-bezier(.76, 0, .24, 1)

    Heavy start and stop, like machinery. Rollers, page turns, rules drawing.

    Inkcubic-bezier(.33, 1, .68, 1)

    Fast spread that slows as it soaks in. Reveals, hovers, cursor.

    Settlecubic-bezier(.34, 1.56, .64, 1)

    Slight overshoot, then rest. Type being set, clippings landing.

    Slamcubic-bezier(.7, 0, .84, 0)

    Accelerates into impact. Used only for stamps.

    Flick150 ms
    Hover states, button presses
    Quick300 ms
    Stamps, menus, small UI changes
    Paper700 ms
    Reveals, headlines, clippings
    Press1200 ms
    Page transitions, the press start

    All twenty, in order of appearance

    "Show me" scrolls to the motion in the prototype and plays it. Every motion has a reduced-motion version for visitors who have turned animation down on their device.

    Build notes

    Ambitious, but built to stay fast

    Everything shown here is production technique, not a video. This prototype runs on the same tools the site would use.

    Tools

    • GSAP with ScrollTrigger for sequences and scroll-linked motion. Free for commercial use.
    • The browser's View Transitions API for page changes, with GSAP as a fallback.
    • CSS only for loops: ticker, bulbs, hovers.

    Performance

    • Only transform, opacity, clip-path and masks are animated, so motion stays on the GPU.
    • Off-screen animations pause; photos lazy-load as modern formats.
    • Target: smooth 60 fps on a mid-range Android phone.

    Accessibility

    • Every motion has a reduced-motion version (listed in the spec).
    • The press start plays once per visit and never blocks reading or ordering.
    • No flashing above 3 times per second.
    Approve the motion setOr mark any of the twenty to cut or tone down.
